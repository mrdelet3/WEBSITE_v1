# Site Structure: Alexey Kukhtin Sculpture

## Vision

A high-end digital gallery experience showcasing sculpture collections. The site must be responsive, support light/dark modes, and provide a seamless checkout experience.

## Sitemap

- [ ] **Home / Store** (`/`)
  - Display current collection (Gypsum).
  - Grid of products.
- [ ] **Product Detail** (`/store/:id`)
  - Immersive view of a single sculpture.
  - Gallery of images.
  - "Add to Cart" and "Inquire" actions.
- [ ] **Checkout** (`/checkout`)
  - 3-step process: Shipping Details, Shipping Method, Payment.
  - Order summary sidebar.

## Roadmap

1. **Foundation**: Setup Vite, Tailwind, Shadcn, Fonts.
2. **Components**: Build core UI (Sidebar, Buttons, Inputs, ProductCard).
3. **Pages**: Implement Home, Product Detail, Checkout.
4. **Logic**: State management for Cart (local storage or context).
5. **Refinement**: Animations, Transitions, Responsive tweaks.
